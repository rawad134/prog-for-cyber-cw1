# Task 3 – IP Address Validator

## Description
This task involved developing an IP address validation program using Python. The program checks whether an IP address entered by the user is valid.

## Features
- Accepting IP address input.
- Validating IP address formats.
- Checking invalid IP addresses.
- Displaying validation results.

## Testing
The program was tested with valid and invalid IP addresses to verify that the validation functionality worked correctly.
