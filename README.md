# prog-for-cyber-cw1

## Overview
This repository contains my Python programming coursework for Cyber Security. It includes five tasks developed to demonstrate programming skills and basic cyber security functionality.

## Coursework Tasks

### Task 1 – Security Tool
A Python security tool incorporating login authentication and security-related functionality.

### Task 2 – Security Event Logger
A Python program for recording and managing security events.

### Task 3 – IP Address Validator
A Python program for validating IP addresses and checking input formats.

### Task 4 – Security Incident Manager
A Python program for managing security incidents and incident-related information.

### Task 5 – Cyber Security Utilities
A collection of reusable Python cyber security utility functions.
